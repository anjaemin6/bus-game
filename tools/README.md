# 검사 도구

게임을 고친 뒤 올리기 전에 돌려 보는 도구예요.

| 도구 | 하는 일 | 쓰는 법 |
|---|---|---|
| `check-levels.js` | 보통·어려움 모든 단계를 컴퓨터로 끝까지 풀어 보고, 못 깨는 단계가 있는지, 빠듯한 판인지, 만드는 데 얼마나 걸리는지 보여 줘요 | `node tools/check-levels.js` |
| `play.js` | 브라우저에서 실제로 차를 눌러 몇 단계를 끝까지 해 봐요 (Playwright 필요) | `node tools/play.js easy 5 hard 12` |

- 두 도구 모두 `index.html`을 그대로 읽어서 써요. 따로 고칠 파일은 없어요.
- `play.js`는 손님이 다 탈 때까지 기다렸다가 다음 차를 눌러요 (왼쪽 칸부터 타는 규칙 때문).
